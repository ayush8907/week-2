# Week 2 — React Fundamentals

This project demonstrates all five assignment requirements:
1. Product information component.
2. Props and state.
3. To-Do app with add, complete, and delete.
4. React Router page navigation.
5. Component-specific CSS Modules.

## Run it
Install Node.js (LTS recommended), open this folder in VS Code, and run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

Build check: `npm run build`

## Where requirements are implemented
- Product component and quantity state: `src/components/ProductCard.jsx`
- Props and cart state: `src/pages/Products.jsx`
- To-Do app: `src/pages/Todo.jsx`
- Router: `src/App.jsx` and `src/components/Header.jsx`
- CSS Modules: `.module.css` files beside components and pages

Product images load from Unsplash and require internet access. The app itself runs locally.
